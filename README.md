# 📱 Tech205 Store

[![Tailwind CSS](https://img.shields.io/badge/Style-Tailwind_CSS-38B2AC?style=flat-square&logo=tailwind-css)](https://tailwindcss.com/)

Chào mừng bạn đến với mã nguồn của **Tech205 Store** - Dự án trang web tĩnh cửa hàng điện thoại chính hãng. Giao diện được thiết kế theo phong cách hiện đại, tối giản, tập trung vào trải nghiệm người dùng (UX) và đặc biệt được tích hợp **Trợ lý AI thông minh** để tự động hóa việc tư vấn bán hàng.

## ✨ Tính năng nổi bật

- 🎨 **Giao diện hiện đại (Minimalist UI):** Sử dụng Tailwind CSS với tông màu Đen - Trắng - Xanh dương thanh lịch.
- 📱 **Responsive Design:** Hoạt động hoàn hảo và mượt mà trên mọi kích thước màn hình (Mobile, Tablet, Desktop).
- 🖼️ **Hoạt ảnh mượt mà:** Tích hợp Hero Banner Slider tự động chuyển slide, cùng các hiệu ứng hover nổi bật thẻ sản phẩm.
- ⚡ **Tối ưu hóa "Single-file":** Toàn bộ cấu trúc HTML, styling CSS và logic JavaScript được đóng gói tối ưu trong đúng một tệp index.html, cực kỳ nhẹ và dễ dàng triển khai ở bất kỳ đâu.
- 🤖 **Trợ lý ảo AI (Gemini API):** Chatbot nổi ở góc màn hình có khả năng:
  - Tư vấn chọn mua điện thoại theo nhu cầu, ngân sách.
  - Cung cấp thông tin chi tiết về các sản phẩm chủ lực (iPhone 17 Pro Max, Galaxy S26 Ultra, Xiaomi 17 Pro, Oppo Find X9).
  - Trả lời các câu hỏi về chính sách bảo hành, thu cũ đổi mới, trả góp của cửa hàng.
  - Giao tiếp thân thiện, tự nhiên nhờ cơ chế Prompt Engineering tối ưu.

## 🛠 Công nghệ & Công cụ sử dụng

- **Cốt lõi:** HTML5, CSS3, Vanilla JavaScript (ES6+).
- **Framework CSS:** Tailwind CSS (Nhúng trực tiếp qua CDN).
- **Trí tuệ nhân tạo (AI):** Google Gemini API.
- **Hình ảnh:** Hình ảnh chất lượng cao từ Unsplash.
- **Font chữ:** Google Fonts (Inter).

## 🚀 Hướng dẫn cài đặt (Local)

Vì đây là dự án tĩnh (Static), bạn không cần cài đặt Node.js hay thiết lập server phức tạp.

1. **Clone repository này về máy:**
`git clone https://github.com/ptpit369-tech/Tech205-Store.git`

2. **Cấu hình AI Chatbot:**
   - Mở tệp index.html bằng Code Editor (như VS Code).
   - Tìm đến dòng `const apiKey = "";` (trong thẻ script ở cuối file).
   - Đăng ký và lấy API Key miễn phí tại Google AI Studio, sau đó dán vào giữa hai dấu ngoặc kép.

3. **Khởi chạy:**
   - Mở trực tiếp tệp index.html bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari...) để xem kết quả.
